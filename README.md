# Employee Salary Calculator

A desktop application developed using Java Swing to calculate employee salaries through a simple graphical user interface.

## Features
- Enter employee name and ID
- Input basic salary, allowances, and deductions
- Calculate gross salary and net salary
- Validate numeric inputs and reject negative values
- Prevent deductions from exceeding gross salary
- Clear form fields and reset calculation results

## Technologies Used
- Java
- Java Swing and AWT
- Object-Oriented Programming (OOP)

## How to Run
1. Install the Java Development Kit (JDK).
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Compile the application using `javac Main.java`.
5. Run the application using `java Main`.

## Salary Calculation
- Gross Salary = Basic Salary + Allowances
- Net Salary = Gross Salary − Deductions

## Purpose
This project demonstrates Java programming fundamentals, GUI development, event handling, input validation, and basic salary calculation logic.
